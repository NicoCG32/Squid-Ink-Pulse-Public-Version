# InformeSquidInkPulse

## Resumen

Este archivo resume el informe integrador del proyecto. La versión extensa y formal se mantiene en el PDF de la misma carpeta.

## PuntosClaves

- Squid Ink-Pulse es un endless runner 2D en Unity.
- La mecánica central es Ink-Pulse, basada en riesgo y recompensa.
- El proyecto incluye progresión de run, boss principal, gadgets y sistema de tienda/in-run como diseño o extensión.
- El desarrollo se organiza con SCRUM.
