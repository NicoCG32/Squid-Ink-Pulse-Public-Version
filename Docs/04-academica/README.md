# 04 · Documentación académica y formativa

[← Índice](../README.md)

Squid Ink-Pulse nació como proyecto grupal de **Proyecto Integrador Programación Avanzada**, asignatura del quinto semestre de Ingeniería Civil en Computación Informática de la **Universidad Católica del Norte**, con una carga de **5 SCT**.

El curso nos daba libertad para elegir el videojuego. Los grupos se conformaron por sorteo; mientras construíamos la identidad **Yeco Works**, una lluvia de ideas dio origen a **Squid Ink-Pulse**.

El equipo estuvo formado por **Pablo Guzmán, Rodrigo Cortés, Mauricio Muñoz, Inti Santibáñez y Matías Palacios**. Sus roles y los derechos sobre los recursos se registran en [LICENSING.md](../../LICENSING.md).
